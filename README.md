# 🎀 Sobre

Um projeto acadêmico simples, para treinar o uso da navegação dinâmica com React Router Dom

## 🛠️ Tecnologias utilizadas

- [React Router Dom](https://mui.com](https://reactrouter.com/)) — essência do projeto: navegação entre as páginas
- [React](https://react.dev/) — biblioteca para construção da interface
- [Vite](https://vitejs.dev/) — servidor de desenvolvimento e build
- [Tailwind CSS](https://tailwindcss.com/) — estilização utilitária
